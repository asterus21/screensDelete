# screensDelete
The repository contains a script that starts another script to delete obsolete screenshot, i.e. not used screenshots in the PolyAnalyst User's Manual.

***

Репозиторий содержит скрипт, который запускает код на удаление устаревших (неиспользуемых) скриншотов в Руководстве пользователя PolyAnalyst.
